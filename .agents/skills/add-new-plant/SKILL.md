# 新規草花登録・画像追加スキル (add-new-plant)

ユーザーが「草花登録して」や「〇〇を登録して」などと発言した場合、以下の手順に沿って手続きを進めるニダ。このスキルは必ず**日本語**で、かつ語尾に「**ニダ**」をつけて対応するニダ。

## 手順1: 草花名の確認
追加したい草花の名前（和名。例: 「アダン」）を確認するニダ。
もし既にユーザーの発言に「〇〇を登録して」と書かれている場合は、その名前を使用するニダ。そうでない場合は、ユーザーに「どの草花を登録するニダ？」と尋ねるニダ。

## 手順2: フォルダへのファイルの配置と自動判別
「kusabana_touroku」フォルダにMarkdownファイルや画像ファイルを配置するニダ。
* **自動判別機能**: 
  - ファイル名が「新規 テキスト ドキュメント.md」や「2026xxxx.jpg」など、草花名を含まない名前であっても、フォルダ内の「唯一のmd」や「すべての画像」をスクリプトが自動検知してリネーム登録するニダ！そのため、事前リネームは原則不要ニダ。

## 手順3: 登録の実行（2つの方法）

ユーザー自身が登録する場合は **方法A**、AIエージェントが代行する場合は **方法B** を推奨するニダ。

### 方法A: JSON編集画面（Web UI）からワンクリックで登録
1. JSON編集サーバーが起動していることを確認し、ブラウザで [http://localhost:8000/index.html](http://localhost:8000/index.html) を開くニダ。
2. ナビゲーションバーの **「草花登録ニダ」** ボタンをクリックするニダ。
3. ポップアップに入力欄が出るので、登録したい草花名（和名）を入力して「登録を実行するニダ」をクリックするニダ。
4. スクリプトが裏で自動実行され、plants.jsonの更新と画面への即時反映が完了するニダ！

### 方法B: コマンドラインでの直接実行（AIエージェント代行用）
草花名（和名）が特定できたら、`run_command` を使用して自動登録スクリプトを直接実行するニダ。
```bash
node .agents/skills/add-new-plant/scripts/register_plant.cjs "草花名"
```
（Cwd は `C:\Gravity\amamikusabana_2` とするニダ）

## 手順4: 実行結果とエラー処理

- **成功した場合**:
  - バックアップが作成され、JSONが正常に更新されたことを伝えるニダ。
  - リネームされた Markdown ファイルが `C:\Gravity\KUSABANA_SEIRI\motomemo_md` フォルダへ移動されるニダ。
  - もし移動先に同名の Markdown ファイルが既に存在する場合、移動は行われず「`mdがすでにあったのでmotomemo_mdには追加できませんニダ`」という警告が出るニダ。
- **一部の画像が移動先に重複していた場合**:
  - スクリプトから「`id_nn.jpg`は既存しています。調べてから自分でimagesフォルダに移動してくださいニダ。」という旨の警告が出力されるニダ。その警告文をそのままユーザーに表示して注意を促すニダ。
- **エラーが発生した場合**:
  - スクリプトが出力したエラー（例：「その草花mdは既にあるので新規登録できません」「〇〇を含むMarkdownファイルが見つかりません」など）をそのままユーザーに伝え、処理を中断するニダ。

JSON編集画面をあらかじめ起動しておけば、サーバーの再起動などをしなくても画面に即時反映されるニダ！もし起動していない場合は `C:\Gravity\KUSABANA_SEIRI\JSON_EDIT\run_server.bat` を起動して画面を開くニダ！
