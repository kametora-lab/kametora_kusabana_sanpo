# 奄美の草花さんぽ帖 Instagramカルーセル作成スキル (create-insta-carousel)

ユーザーが「カルーセル作成して」「インスタのカルーセル作って」と依頼した際、このスキルに従って **美しい4:3写真を前面に出し、スマホの小さな画面や40代〜60代女性の目でも1秒でクッキリ読める特大文字デザインのカルーセル画像（5枚構成）＋保存を促すキャプション** を一括作成するニダ。

---

## 【最優先】ターゲット読者設定・運用原則（絶対厳守ニダ）

1. **読み手（ターゲットペルソナ）の設定**
   - **属性**：時間とお金にゆとりのある40代〜60代の自然・野草・園芸好きな女性（奄美大島への旅や島暮らしに関心が高い層）。
   - **トーン＆マナー**：知的で上品、情緒的で落ち着いた世界観。若者向けの煽り文句（「ヤバい」「衝撃」「必見！」など）は品位を損ね離脱されるため**厳禁**とするニダ。
   - **エンゲージメント心理**：単なる面白いネタではなく、「花言葉」「昔ながらの暮らしの知恵（生薬・染め物・魔除け等）」「次の奄美旅行のためのガイド」に強く共感し、友人や旅仲間にDMでシェア（Sends）したり、保存（Saves）する傾向を捉えるニダ。

2. **過去採用植物の完全重複除外（毎回異なる草花を紹介）**
   - 過去に作成された設定ファイル（`insta_carousel/configs/*.json`）をすべてスキャンし、すでに紹介した植物ID・名前を除外リストに登録するニダ。
   - 毎回必ずまだ投稿していない新しい草花を優先選定し、同じ植物が重複してカルーセル化されるのを完全に防止するニダ。

3. **投稿成績ログの参照と更新（検証サイクルの運用）**
   - 成績ログ [insta_carousel/performance_log.md](file:///C:/Gravity/amamikusabana_2_new/insta_carousel/performance_log.md) を毎回の作成開始時に必ず読み、過去の成績・所見・検証仮説を確認するニダ。
   - 事前提案（次項）の際に、**「前回までの成績の要点」「今回検証する仮説（変える要素は1〜2個に絞る）」**を併せて提示するニダ。
   - 未記入の投稿がある場合は、ユーザーにインサイト数値（ビュー、フォロワー外%、いいね・コメント・保存・シェア、プロフィールアクセス、実施施策、投稿時間帯、フォロワー数）の提供を依頼し、ログに追記するニダ。
   - 母数が小さい（閲覧者数十人程度）うちは1投稿で断定せず、最低5投稿分の傾向で判断するニダ。これまでの施策（BGM・ストーリーズ誘導など）は仮説であり、ログで検証するニダ。

4. **画像生成前の「事前提案・確認」フロー（勝手な先行生成の禁止）**
   - 「カルーセル作成して」と依頼されても、**いきなり画像を生成してはならないニダ**。
   - 必ず画像作成（ステップ2以降）に進む前に、**「今回採用する草花3種類」「選定テーマ」「各植物の選定理由・見どころ」** をチャット上でユーザーに提案・提示し、ユーザーの合意（OK）を得てから画像生成スクリプトを実行すること！

## 絶対厳守のデザイン・表記ルール（ユーザー合意事項ニダ）

1. **図鑑No（`0078` など）はユーザー非開示のため絶対に入れないこと**
   - スライド画像内にも、Instagramの投稿文（キャプション）にも、`図鑑 No.XXXX` や内部IDは一切記載してはならないニダ。
   - 植物スライドの左上バッジは `01 ｜ 奄美の草花さんぽ帖` のように通し番号とサイト名にするニダ。
2. **写真を前面に出し、4:3の横長写真を切らずに活かすこと**
   - 1枚目（表紙）：白い額縁や余白を作らず、画面上部85%にメイン写真を大きく配置し、下部は写真自身のブラー（ぼかし）グラデーションで繋ぐニダ。
   - 2〜4枚目（植物図鑑スライド）：上部 `1080×810px`（完全な4:3比率）に横幅いっぱいでメイン写真を配置し、右下境界線上に2枚目の4:3サブ写真（花と実の比較など、`336×252px`）を添えるニダ（`KAMETORA` 透かしロゴとの重なりは気にしなくてよいニダ）。
3. **スマホ・3列グリッド一覧でも1秒で読める特大文字（Yu Mincho Demibold / Yu Gothic Bold）**
   - 1枚目メインタイトル：**72pt〜56pt**（2行構成、1行あたり9〜12文字以内を目安に短く力強いコピーにするニダ）
   - 2〜4枚目植物名：**58pt**、別名・方言名：**28pt**、解説文：**33pt（太明朝体・2〜3行・計60〜75文字程度に凝縮）**、観察ポイント：**28pt（1行・25文字以内）**
   - **絵文字（`🔍` `📕` `☕️` `✦` 等）は画像内テキストに絶対に使わないこと**：Windowsの游明朝・游ゴシックには絵文字グリフがなく `☒`（豆腐）に文字化けするため、画像内では必ず日本語標準記号（`◆` `●` `★` `①` `②` `▼` `＞＞`）のみを使うニダ（キャプション本文には絵文字を使ってよいニダ）。
4. **最終スライド（5枚目）の2大サイト名称は一字一句変えずに表記すること**
   - ① 草花デジタル図鑑：**『 奄美の草花さんぽ帖 』**
   - ② 奄美のさんぽブログ：**『 奄美☆かめとらの奄美生活 』**
5. **動画（Remotion）ではなく、Python + Pillow スクリプト（`insta_carousel/generate_carousel.py`）で高速・高画質PNGとして生成すること**

## 実行ステップ

### ステップ1：テーマと対象植物（3種）の選定・事前確認（毎回重複を防ぐニダ！）
1. **過去の採用履歴の確認（植物の重複を完全に防止）**：
   - `C:\Gravity\amamikusabana_2_new\insta_carousel\configs\` 配下にある過去のJSON設定ファイル（または `history.json` / 過去の出力フォルダ名）を調べ、**過去のカルーセルですでに採用された植物名・IDを確認して除外リストを作成するニダ**。
   - 毎回必ずまだ投稿していない新しい草花を優先してピックアップし、同じ植物が連続・重複して登場しないようにするニダ。
2. **メインターゲット層の意識**：読者は「時間とお金にゆとりのある40代〜60代の自然・草花好きな女性」ニダ。若者向けの煽り（「ヤバい」「衝撃」など）は厳禁とし、知的で上品・情緒的な世界観で統一するニダ。
3. ユーザーが植物名やテーマ（例：「10月の赤い実と紫の花」「アダンとハイビスカスと…」など）を指定している場合はそれを使うニダ。
4. 指定がない場合や「おまかせ」「今の季節でカルーセル作成して」と言われた場合は、[src/data/plants.json](file:///C:/Gravity/amamikusabana_2_new/src/data/plants.json) から過去未採用のものを対象に、現在の月（`months`）や季節・色・場所に合う魅力的な植物を **3種類** ピックアップするニダ。
   - **1枚目（表紙）とスライド2（`plants[0]`）の「第2の表紙」設計**：Instagramには1枚目をスルーしたユーザーに次回「2枚目」を先頭にして再表示するアルゴリズム（セカンドチャンス）があるニダ。そのため、1枚目と2枚目には最も視覚的インパクトや物語性がある主役植物（例：ハート型の赤い実、宝石のような青い実、珍しい形の花など）を配置し、2枚目単体で見ても思わず手が止まる情緒的なキャッチコピーにするニダ。
5. 選んだ各植物について、`public/images/` 内の画像ファイル（`<id>_00.jpg`, `<id>_01.jpg` 等）を `read_file` で実際に目視確認し、一番美しい写真を `main_img`、花と実の対比や葉のアップなど補完になる写真を `sub_img` に選ぶニダ。
6. **【超重要・事前確認必須】画像を生成する前に、必ずユーザーへ採用候補の植物3種・テーマ・選定理由・見どころを提示し、ユーザーの合意を得てからステップ2に進むこと！勝手に先行して画像生成してはならないニダ！**

### ステップ2：設定JSONファイルの作成（DMシェア＆保存を誘発するライティングニダ）
`C:\Gravity\amamikusabana_2_new\insta_carousel\configs\carousel_<YYYYMMDD_HHMMSS>.json` に以下のフォーマットで設定JSONファイルを作成するニダ（`write_file` ツールを使用）。

#### スライド内テキストのアルゴリズム最適化ルール
- **知的なお裾分け（DMシェア / Sends 誘発）**：大人女性は「知的な発見」「島の暮らしの物語」「旅の計画」を友人や旅仲間にシェアするニダ。`short_desc`（解説文）には単なる見た目の説明だけでなく、**「花言葉」「方言名の由来」「島での昔ながらの知恵（薬草・魔除け・染め物など）」**といった誰かに話したくなるストーリーを必ず盛り込むニダ。
- **旅・散策の目安（保存 / Saves 誘発）**：「いつか奄美に見に行きたい」と思わせるため、`point`（観察ポイント）や解説文には形の特徴だけでなく**「出会える場所の風景（海岸のサンゴ岩場、森の林道沿い、集落の生垣など）」**を具体的に入れるニダ。

#### 文字数・配色の目安（はみ出し防止ニダ）
- `cover.title_line1` / `title_line2`：各行 **11文字以内**（最大でも13文字以内）
- `plants[].catchphrase`：**24文字以内**
- `plants[].short_desc`：**全角60〜78文字程度**（改行 `\n` を1回入れて2〜3行に収める。4行を超えると下の観察ポイント帯に近づきすぎるため簡潔にするニダ）
- `plants[].point`：**24文字以内**
- `plants[].accent_rgb`：その植物の花や実の色に合わせた上品な深みのあるRGB（赤系 `[168, 52, 52]`、紫系 `[107, 58, 158]`、青紫系 `[64, 82, 156]`、黄・橙系 `[184, 110, 28]`、緑系 `[46, 92, 62]`、ピンク系 `[176, 62, 108]` など）
