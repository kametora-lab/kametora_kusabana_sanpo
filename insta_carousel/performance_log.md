# Instagramカルーセル 投稿成績ログ

投稿ごとの成績と施策を記録し、次回以降の制作・検証に活かすためのログ。
計測は投稿から2日後（48時間）のインサイト数値を基本とする。

## 記録フォーマット

| 項目 | 内容 |
|---|---|
| 設定ファイル | `configs/carousel_YYYYMMDD_HHMMSS.json` |
| 投稿日時 | 投稿した日時（時間帯を含む） |
| フォロワー数 | 投稿時点 |
| 採用植物 | 3種 |
| 実施施策 | BGM / 位置情報 / ストーリーズ誘導 / アンケートスタンプ など（やった・やっていないを明記） |
| ビュー / 閲覧者 | |
| フォロワー外ビュー % | |
| いいね / コメント / 保存 / シェア | |
| プロフィールアクセス / 外部リンクタップ | |
| 所見・次回の検証仮説 | |
